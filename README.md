# AI Камера — распознавание объектов в браузере

Программа получает видео с камеры компьютера, телефона, экрана или IP-камеры и распознаёт объекты нейросетью
**YOLO** (Ultralytics: YOLO26, YOLO11, YOLOv8). Результат транслируется на веб-страницу: объекты обведены рамками
и подписаны по-русски, рядом показано, где находится каждый объект и сколько объектов каждого вида в кадре.
Снимки сохраняются в галерею на сайте вместе с автоматическим описанием.

Подробная документация: [`docs/AI_Camera_Documentation.docx`](docs/AI_Camera_Documentation.docx).

## Возможности

- **Источники видео:**
  - камеры компьютера — находятся автоматически, с названиями (кнопка ⟳ ищет заново);
  - камера этого устройства через браузер — ноутбук, планшет или телефон как беспроводная камера;
  - захват экрана, окна или вкладки через браузер;
  - IP-камеры (`rtsp://`, `http://`) и видеофайлы.
- **24 модели в пяти группах:**
  - YOLO26, YOLO11 и YOLOv8 (Nano … Extra Large) — 80 классов COCO;
  - YOLOv8 Open Images (Nano … Extra Large) — **601 класс**, все с русскими названиями;
  - YOLOE-26 (Small … Extra Large) — ищет **любые объекты по названию**: впишите на сайте «очки», «кружка», «red car»;
  - собственные `.pt` из папки `models/`.

  Список классов на сайте меняется вместе с выбранной моделью. Под списком моделей показаны число классов,
  точность (mAP), число параметров, объём вычислений и скорость.
- **Вычислительное устройство:** «Авто» (видеокарта NVIDIA → графика Apple Silicon → процессор) или конкретное устройство
  из найденных на компьютере; видеокарта без поддержки в PyTorch показывается с подсказкой, как её включить.
- Распознавание 80 видов объектов, рамки и подписи на русском или английском, счётчик объектов и FPS прямо на видео.
- Список «что в кадре и сколько» с расположением каждого объекта: слева, вверху справа, в центре и т. п.
- Настройки применяются сразу: порог уверенности, IoU, размер входа сети, классы, оформление, разрешение, зеркало, качество.
- Снимок по кнопке или клавише **S**; галерея с поиском, оригиналом, подписями, скачиванием и удалением.
- Доступ с других устройств локальной сети и **через VPN** (WireGuard, AmneziaVPN, OpenVPN, Tailscale, ZeroTier).

## Установка и запуск (Windows, macOS, Linux)

Нужен только Python 3.9 или новее (рекомендуется 3.11–3.12). Запуск одной командой:

| Система | Команда |
|---|---|
| Windows | `python main.py` |
| macOS / Linux | `python3 main.py` |

При первом запуске `main.py` сам:

1. создаёт виртуальное окружение `.venv` и устанавливает зависимости из `requirements.txt`
   (при наличии видеокарты NVIDIA ставит PyTorch с поддержкой CUDA);
2. скачивает модель в папку `models/` (Nano — около 5 МБ);
3. выбирает вычислительное устройство, способ доступа к камере и шрифт с кириллицей для текущей ОС;
4. выбирает свободный порт (на macOS по умолчанию **8080**, потому что порт 5000 занят AirPlay) и открывает браузер.

### Видеокарта NVIDIA (Windows и Linux)

При первом запуске программа сама ставит PyTorch с CUDA, если в системе есть драйвер NVIDIA: по `nvidia-smi` она узнаёт,
какую версию CUDA поддерживает драйвер, берёт самую новую подходящую сборку (cu130 … cu118) и проверяет, что видеокарта
действительно работает, — иначе пробует следующую. Если окружение уже создано без видеокарты:

```bash
python main.py --install-cuda      # Windows
python3 main.py --install-cuda     # Linux
```

**Linux.** Нужен только драйвер NVIDIA — CUDA Toolkit ставить не надо. Проверка: команда `nvidia-smi` показывает видеокарту.
Если её нет, программа заметит видеокарту на шине PCI и подскажет, как поставить драйвер:

| Дистрибутив | Драйвер |
|---|---|
| Ubuntu, Mint | `sudo ubuntu-drivers install` |
| Debian | `sudo apt install nvidia-driver firmware-misc-nonfree` (репозиторий non-free) |
| Fedora | `sudo dnf install akmod-nvidia` (RPM Fusion) |
| Arch, Manjaro | `sudo pacman -S nvidia` (или `nvidia-open`) |
| WSL2 | драйвер ставится только в Windows |

После перезагрузки: `python3 main.py` (или `python3 main.py --install-cuda`, если `.venv` уже был создан).
В консоли появится строка «Вычисления: NVIDIA GPU (…)». Подробно — документация, раздел 6.5.

### Доступ по сети и через VPN

Сервер слушает все адреса (`0.0.0.0`). При запуске в консоль выводятся адреса для подключения:

```
  Откройте в браузере:  http://127.0.0.1:5000
  С телефона / другого устройства в сети:  http://192.168.1.77:5000
  Через VPN (для устройств в той же VPN): http://10.8.1.1:5000
```

Виртуальные адаптеры (VirtualBox, VMware, WSL) пропускаются. Для доступа через VPN сервер VPN должен
разрешать обмен между клиентами, а брандмауэр — входящие подключения к Python.

### Свои названия объектов (YOLOE)

Выберите модель из группы «YOLOE-26 — свои названия объектов» и впишите в карточке «Свои названия объектов», что искать:

| Ввод | Результат |
|---|---|
| `кружка` | точное название класса из словаря (605 названий): запрос `mug` |
| `человек в каске`, `жёлтые цветы в горшке` | фраза переводится встроенным переводчиком: `person in hard hat`, `yellow flowers in pot` |
| `red car` | английский текст передаётся модели как есть |
| `кружка с котом = cat mug` | подпись до «=», запрос к модели — после |

YOLOE понимает только английский, поэтому в проект встроен **простейший локальный переводчик** (`translator.py`):
без интернета и дополнительных моделей он переводит короткие фразы по словам — отбрасывает русские окончания
(«зелёная», «зелёные» → green), сначала ищет названия из нескольких слов и переводит предлоги. Словарь — 605 названий
классов и около 350 частых слов (цвета, материалы, одежда, техника, посуда, еда, животные…). Непереведённые слова
помечаются значком ⚠ — для них укажите «подпись = english».

Первое применение скачивает текстовый кодировщик MobileCLIP (~254 МБ) и пакет `clip` — нужен интернет и Git.
Дальше смена списка занимает около 2 секунд.

### Телефон как камера

Сервер по умолчанию слушает все адреса (`0.0.0.0`), поэтому страница открывается с других устройств сети (в общественных сетях используйте `--host 127.0.0.1`). Браузер даёт доступ к камере только по HTTPS или на `localhost`, поэтому для камеры телефона нужен HTTPS:

```bash
python main.py --https
```

Откройте на телефоне адрес из консоли (`https://192.168.x.x:5000`), примите предупреждение о самоподписанном сертификате,
выберите источник «🌐 Камера этого устройства» и нажмите «Начать трансляцию».

### Особенности систем

| Система | Что учесть |
|---|---|
| Windows | Камеру не должны занимать другие программы (Камера Windows, Zoom, Teams). |
| macOS | Python 3.12 с python.org или Homebrew. Разрешите доступ к камере: Системные настройки → Конфиденциальность и безопасность → Камера → Терминал, затем перезапустите программу. |
| Linux | Пользователь должен быть в группе `video`. На минимальных системах: `sudo apt install python3-venv libgl1 libglib2.0-0`. |

### Параметры командной строки

| Параметр | Описание |
|---|---|
| `--host 127.0.0.1` | только этот компьютер. По умолчанию `0.0.0.0` — страница доступна с других устройств сети (адреса Wi-Fi/Ethernet выводятся в консоль) |
| `--port 8080` | другой порт (если занят, берётся следующий свободный) |
| `--https` | HTTPS с самоподписанным сертификатом — нужен для камеры телефона через браузер |
| `--camera 1` | другая камера или URL потока, только на этот запуск |
| `--device cpu` | вычислительное устройство на этот запуск: `auto`, `cpu`, `cuda`, `cuda:N`, `mps` |
| `--no-browser` | не открывать браузер автоматически |
| `--install-cuda` | включить видеокарту NVIDIA: PyTorch со сборкой CUDA под драйвер, проверка и выход |

Чтобы при первой установке не качать PyTorch с CUDA (2–3 ГБ), задайте переменную окружения `AI_CAMERA_CPU_ONLY=1`.
Если окружение уже создано без CUDA, а видеокарта NVIDIA есть — выполните `python main.py --install-cuda`.

## Модели

| Модель | Классов | mAP50-95 | CPU i7-11700F (замер) | RTX 3060 Ti (замер) |
|---|---|---|---|---|
| YOLO26 Nano | 80 | 40,9 (COCO) | 41 мс · 24,6 FPS | 17 мс · 58 FPS |
| YOLO26 Medium | 80 | 53,1 (COCO) | 206 мс · 4,9 FPS | 21 мс · 47 FPS |
| YOLO26 Extra Large | 80 | 57,5 (COCO) | 516 мс · 1,9 FPS | 29 мс · 34 FPS |
| YOLOv8 Open Images Nano … X | 601 | 18,4 … 36,3 (Open Images) | — | — |
| YOLOE-26 Small … X | любые | 30,8 … 40,6 (LVIS) | — | — |

mAP — официальные данные Ultralytics (вход 640); метрики разных наборов данных между собой не сравниваются.
Таблицы по всем моделям, график «точность против скорости» и советы по выбору — в документации, глава 5.

## Структура проекта

```
main.py          — точка входа и веб-сервер Flask: страницы, видеопоток, приём кадров из браузера, API
bootstrap.py     — первый запуск: создание .venv и установка зависимостей
platform_info.py — особенности ОС: камеры, шрифты, порт, вычислительные устройства
camera.py        — фоновый поток: кадр с камеры или из браузера → распознавание → MJPEG
detector.py      — модель YOLO на выбранном устройстве, рамки и подписи, описания
gallery.py       — снимки и их описания (gallery/*.jpg + *.json)
settings.py      — каталог моделей и настройки (settings.json)
labels_ru.py     — русские названия COCO, перевод и разбор своих названий для YOLOE
labels_oiv7_ru.py — русские названия 601 класса Open Images V7
translator.py    — простейший локальный переводчик русских названий на английский для YOLOE
templates/       — HTML-страницы
static/          — CSS и JavaScript (broadcast.js — трансляция камеры и экрана из браузера)
docs/            — документация (.docx)
```

## API

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/video_feed` | MJPEG-поток с разметкой |
| GET | `/api/status` | источник, устройство, объекты в кадре, количество, FPS |
| GET/POST | `/api/settings` | прочитать или изменить настройки |
| GET | `/api/models` | каталог моделей с характеристиками |
| GET | `/api/devices` | вычислительные устройства компьютера |
| GET | `/api/classes` | классы текущей модели с русскими названиями |
| GET | `/api/vocab` | свои названия для YOLOE: подпись, запрос к модели, найден ли перевод |
| GET | `/api/cameras` | камеры компьютера с названиями (`?refresh=1` — искать заново) |
| POST | `/api/push_frame` | кадр из браузера (тело — JPEG) |
| POST | `/api/snapshot` | сделать снимок (`{"note": "..."}`) |
| GET | `/api/gallery` | список снимков |
| PATCH/DELETE | `/api/gallery/<id>` | изменить подпись или удалить снимок |
