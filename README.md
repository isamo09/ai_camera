# AI Камера — распознавание объектов в браузере

Программа захватывает видео с веб-камеры через **OpenCV** и распознаёт объекты нейросетью **YOLO26 / YOLO11** (Ultralytics).
Результат транслируется на веб-страницу: объекты обведены рамками и подписаны по-русски,
рядом показано, где находится каждый объект и сколько объектов каждого вида в кадре.
Снимки сохраняются в галерею на сайте вместе с автоматическим описанием.

## Возможности

- Видео с камеры в реальном времени (USB-камера, встроенная камера, IP-камера по `rtsp://` / `http://`).
- Распознавание 80 видов объектов (люди, животные, транспорт, посуда, техника и т. д.).
- Рамки и подписи на русском или английском языке, процент уверенности, счётчик объектов прямо на видео.
- Боковая панель со списком «что в кадре и сколько» и расположением каждого объекта: слева, вверху справа, в центре и т. п.
- Настройки в браузере, применяются сразу:
  - модель (Nano, Small, Medium или Large) и размер входа сети;
  - порог уверенности и порог перекрытия (IoU);
  - выбор классов, которые нужно искать;
  - рамки, подписи, счётчик, FPS и толщина линий;
  - камера, разрешение, зеркальное отражение и качество видео.
- Снимок по кнопке или клавише **S**, с необязательной подписью.
- Галерея: поиск по объектам и подписям, просмотр снимка с разметкой или оригинала, редактирование подписи, скачивание и удаление.

## Установка и запуск (Windows, macOS, Linux)

Нужен только Python 3.9 или новее. Запускается одной командой на любой системе:

| Система | Команда |
|---|---|
| Windows | `python main.py` |
| macOS / Linux | `python3 main.py` |

При первом запуске `main.py` сам:

1. создаёт виртуальное окружение `.venv` и устанавливает зависимости из `requirements.txt`
   (при наличии видеокарты NVIDIA ставит PyTorch с поддержкой CUDA);
2. скачивает модель (около 5 МБ) в папку `models/`;
3. выбирает вычислительное устройство: видеокарта NVIDIA → графика Apple Silicon → процессор;
4. подбирает способ доступа к камере (DirectShow / Media Foundation на Windows, AVFoundation на macOS, V4L2 на Linux);
5. выбирает свободный порт (на macOS по умолчанию **8080**, потому что порт 5000 занят AirPlay) и открывает браузер.

Последующие запуски занимают несколько секунд. Если окружение уже активировано вручную, зависимости ставятся в него.

### Особенности систем

| Система | Что учесть |
|---|---|
| Windows | Камеру не должны занимать другие программы (Камера Windows, Zoom, Teams). |
| macOS | При первом запуске разрешите доступ к камере: Системные настройки → Конфиденциальность и безопасность → Камера → Терминал. Затем перезапустите программу. |
| Linux | Пользователь должен быть в группе `video`. На минимальных системах может понадобиться `sudo apt install python3-venv libgl1 libglib2.0-0`. |

### Параметры командной строки

| Параметр | Описание |
|---|---|
| `--host 0.0.0.0` | открыть доступ с других устройств в локальной сети (адрес для телефона будет выведен в консоль) |
| `--port 8080` | другой порт (если занят, берётся следующий свободный) |
| `--camera 1` | другая камера или URL потока (`rtsp://user:pass@192.168.1.10/stream`), только на этот запуск |
| `--device cpu` | принудительно выбрать устройство: `auto`, `cpu`, `cuda`, `mps` |
| `--no-browser` | не открывать браузер автоматически |

Чтобы при первой установке не качать PyTorch с CUDA (2–3 ГБ), задайте переменную окружения `AI_CAMERA_CPU_ONLY=1`.

## Структура проекта

```
main.py        — точка входа и веб-сервер Flask: страницы и API
bootstrap.py   — первый запуск: создание .venv и установка зависимостей
platform_info.py — особенности ОС: камера, шрифты, порт, устройство (CUDA / MPS / CPU)
camera.py      — фоновый поток: захват кадров OpenCV → распознавание → MJPEG-поток
detector.py    — модель YOLO, рамки и подписи (через Pillow, чтобы работала кириллица), описания
gallery.py     — сохранение снимков и их описаний (gallery/*.jpg + *.json)
settings.py    — настройки (сохраняются в settings.json)
labels_ru.py   — русские названия классов
templates/     — HTML-страницы
static/        — CSS и JavaScript
```

## API

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/video_feed` | MJPEG-поток с разметкой |
| GET | `/api/status` | объекты в кадре, количество, FPS |
| GET/POST | `/api/settings` | прочитать или изменить настройки |
| POST | `/api/snapshot` | сделать снимок (`{"note": "..."}`) |
| GET | `/api/gallery` | список снимков |
| PATCH/DELETE | `/api/gallery/<id>` | изменить подпись или удалить снимок |
